# AgentDX Homebrew Tap

Homebrew tap for [AgentDX](https://agentdx.ai) — the flight recorder for AI coding agents.

## Install

```sh
brew tap agentdxhq/tap
brew install agentdx
```

Then run:

```sh
agentdx
```

## Update

```sh
brew update && brew upgrade agentdx
```

## Uninstall

```sh
brew uninstall agentdx
brew untap agentdxhq/tap
```
